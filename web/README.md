# web/ — Angular 22 client

Empty on purpose. Phase 3B of `docs/DEPLOYMENT-PROMPT.md` scaffolds the Angular app here.

Scaffold it with `ng new` from a pinned CLI so it inherits current defaults — standalone
components, signals, zoneless change detection, Vitest — rather than reconstructing them
from memory. Do not hand-write `angular.json`.

`webapp/static/index.html` is the design and behaviour reference. Read it before building.
